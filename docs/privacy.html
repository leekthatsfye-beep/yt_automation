Privacy Policy — LeekThatsFy3 YT Automation

Last updated: 13 September 2026

LeekThatsFy3 YT Automation is a private, single-user tool operated by LeekThatsFy3. It is used solely to render and publish the operator's own instrumental music videos to the operator's own YouTube channel.

What the app accesses

Using Google OAuth, the app requests access to the YouTube Data API and YouTube Analytics API for the operator's channel in order to upload videos, edit their titles, descriptions, tags and thumbnails, manage playlists, post comments, and read the channel's own analytics.

Whose data is involved

Only the operator's own Google account and YouTube channel are connected. The app is not offered to the public, does not collect data from any other person, and has no user accounts of its own.

Storage and sharing

OAuth tokens are stored locally on the operator's computer and are never transmitted to any third party. No personal information is sold, shared, or used for advertising. Analytics data is read only to report on the operator's own channel performance.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account → Security → Third-party access.

Contact

Use the support email shown on the Google sign-in consent screen for this app.
